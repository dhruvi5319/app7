# Requirements: TaskTracker

**Defined:** 2026-05-11
**Core Value:** Users can quickly capture and track tasks so nothing falls through the cracks.

## v1 Requirements

### Task Management

- [ ] **TASK-01**: User can create a task by entering a title and submitting
- [ ] **TASK-02**: User can view all tasks in a list, persisted across browser sessions
- [ ] **TASK-03**: User can mark a task as complete or incomplete
- [ ] **TASK-04**: User can delete a task instantly (no confirmation required)
- [ ] **TASK-05**: User can edit a task's title inline

## v2 Requirements

### Notifications & Reminders

- **NOTF-01**: User can set a due date on a task
- **NOTF-02**: User receives reminder notifications for due tasks

### Organization

- **ORG-01**: User can assign tasks to categories or labels
- **ORG-02**: User can filter tasks by status (all / active / completed)

## Out of Scope

| Feature | Reason |
|---------|--------|
| User authentication / accounts | Single-user focus for v1; simplicity is core value |
| Multi-user collaboration | Out of scope per PROJECT.md |
| Subtasks / nested tasks | Adds complexity; deferred to future |
| Mobile native app | Web-first; mobile later |
| Real-time sync | No backend in v1 |
